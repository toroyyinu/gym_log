## 2. 画面ごとの仕様

### S-1 記録画面（ホーム）

**レイアウト（上から順に）**

記録ボタンをスクロールせずに押せるよう、入力欄を一覧より上に置く。

1. 選択中の種目名（タップすると S-2 が開く）と部位。未選択のときは「種目を選ぶ」ボタンを表示する。
2. 種目の固定メモ（例：「シート位置4」）。登録されている場合だけ表示する。
3. **入力欄**
   - 筋トレ
     - 重量：`[−] 60 kg [＋]`。＋／−で種目の刻み幅ずつ増減する。数字部分をタップすると直接入力できる。
     - 回数：`[−] 10 回 [＋]`。1回ずつ増減する。直接入力もできる。
   - 有酸素：「5.4 有酸素の記録項目」の欄を出す。時間・速度・傾斜（またはレベル・回転数）は −／＋ つき、距離・カロリーは数値欄。下に「途中で設定を変えたときは、主に使った値を（区間ごとに分けて記録してもOK）。」と案内する。
   - 辛さ：5つのボタンから1つを選ぶ。下に、選んだ段階の目安を1行で出す（「3. 辛さの定義」。未選択なら「押すと目安が出ます」）。
   - 備考：1行のテキスト欄（任意）。
   - 記録できない理由（例：「辛さを選んでください」）。
   - ［このセットを記録］ボタン（有酸素は［記録する］）。
4. **今日の記録**：今日この種目で記録した一覧。行を押すと S-4 で修正・削除できる。
5. **前回の記録**：前回その種目をやった日の日付と全記録。前回の記録がない場合は、この欄自体を表示しない。
   - 行を押すと、その値を入力欄に入れる（「前回の②の値を入れました」と表示）。前回の記録を直したいときは S-3 から行う。

**記録の行の表示**
- 筋トレ：`① 60kg × 10回 [普通] 備考`
- 有酸素：`① 30分 ・ 8km/h ・ 傾斜 2% ・ 3.2km [普通] 備考`（入れていない項目は出さない）

**入力欄の初期値**

基準になる1件の記録を決め、その記録の値をそのまま入れる（項目ごとにさらに前の記録へさかのぼることはしない）。

| 状況 | 基準にする記録 | 辛さ | 備考 |
|---|---|---|---|
| 今日すでに記録している | 今日の直前の記録 | 未選択 | 空 |
| 今日まだ記録していない | 前回の日の1件目 | 未選択 | 空 |
| 前回の記録がない | なし。**空欄**にする（必須の欄を入力するまで記録できない） | 未選択 | 空 |

**動作**
- 必須の欄が空、範囲外、または辛さが未選択のときは、記録ボタンを押せない（理由を表示する）。
- 記録すると、日時（端末の現在時刻）をつけて保存し、「今日の記録」に追加する。保存できたことを表示する（例：「②を記録しました」、有酸素は「記録しました」）。
- 記録した直後の表示には［取り消す］ボタンをつけ、約5秒間表示する。押すとその記録を削除する。
- 入力中の値は、ほかの画面へ移って戻ってきても残す（同じ日・同じ種目の場合。アプリを閉じると消える）。
- 最後に選んだ種目を覚えておき、次に画面を開いたときにも選択された状態にする。

### S-2 種目選択シート

- 画面下からせり上がる一覧で表示する。
- **並び順**：最後に記録した日時が新しい種目ほど上。まだ記録のない種目はその後ろに名前順で並べる。この並び順は、履歴・グラフ・設定画面・記録編集シートの種目一覧でも同じにする。
- 各行には、種目名と部位を表示する（例：`ダンベルカール　腕`、`トレッドミル　有酸素`）。
- 上部に絞り込みボタン（すべて／胸／背中／肩／腕／体幹／脚・お尻／有酸素）を置く。
- 「非表示」にした種目は出さない。
- 一番下に「＋ 新しい種目を登録」を置き、S-7 を開く。登録して保存すると、その種目を選んだ状態で S-1 に戻る。

### S-3 履歴画面

- 表示の切り替え：**日付ごと** ／ **種目ごと**
  - 日付ごと：新しい日付が上。日付の下に、その日に行った種目と記録を並べる。
  - 種目ごと：種目を選ぶと、その種目の記録を新しい順に表示する。非表示にした種目も選べる（「（非表示）」と表示）。
- 絞り込み：部位（有酸素を含む）、または筋肉で絞り込める。種目に紐づいた筋肉のいずれかが一致すれば表示する。削除した筋肉は選択肢に出さない。
- 行の表示は S-1 と同じ。行をタップすると S-4 を開く。
- 期間での絞り込みはない（将来の候補。PRD 3.2）。

### S-4 記録編集シート

- 日時・種目・重量・回数（有酸素はその種類の記録項目）・辛さ・備考を修正できる。辛さの目安は S-1 と同じように表示する。
- 種目は、同じ種類（筋トレ／トレッドミル型／バイク型）の種目にだけ付け替えられる。
- 日時の欄は分まで。日時を変えなかった場合は、元の秒まで残す。
- ［削除］ボタンを押すと確認ダイアログを出し、OK なら削除する。

### S-5 グラフ画面

- 上部で種目を選ぶ（並び順は S-2 と同じ）。非表示にした種目も、記録があれば選べる。
- 最初に表示する種目：記録画面で種目を選び直していればその種目、そうでなければ前に見ていた種目。
- まだ1件も記録がないときは、グラフの代わりに「記録すると、ここにグラフが出ます。」と表示する。
- 折れ線グラフ
  - 横軸：日付
  - 縦軸：筋トレは重量（kg）。有酸素は、項目ボタン（トレッドミル型：時間・速度・傾斜・距離・カロリー／バイク型：時間・レベル・回転数・距離・カロリー）で切り替える。
  - 1日につき1点。筋トレは **その日の最大重量**。有酸素は、時間・距離・カロリーは **その日の合計**、速度・傾斜・レベル・回転数は **その日の最大** とする。値を入れていない日は点を出さない。
  - 選んだ期間に点がないときは「この期間の記録はありません。」と表示し、グラフ枠は出さない。
- 点をタップすると、その日の記録一覧を表示する。行を押すと S-4 を開く。
- 表示期間の切り替え：1か月／3か月／すべて。初期値は3か月。

### S-6 設定画面

| 項目 | 内容 |
|---|---|
| 種目の管理 | 種目の一覧（並び順は S-2 と同じ）。タップで S-7。非表示にした種目も「非表示」の印をつけて表示する |
| 筋肉の管理 | 部位ごとの筋肉の一覧。どの種目にも使われていない筋肉は、最初から用意したものも含めて［削除］できる。使っている筋肉には「使用中」と表示し、削除ボタンは出さない。削除した筋肉は消さずに隠し、一覧の下の「削除した筋肉」から［戻す］で元に戻せる。筋肉の追加は S-7 で行う |
| 保存状態 | 最終バックアップ日時、記録の件数、データの永続化（「8」を参照）が許可されているか、ホーム画面から起動しているか |
| データの書き出し | ［バックアップを書き出す（復元用）］［CSVで書き出す（分析用）］。共有シートでは「"ファイル"に保存」を選ぶよう案内する |
| データの読み込み | ［バックアップから復元］（「7.2」を参照） |
| 版 | アプリの版（例：v0.2.0） |

### S-7 種目編集画面

| 項目 | 必須 | 入力方法 | 初期値 |
|---|---|---|---|
| 種目名 | ○ | テキスト | — |
| 種類 | ○ | 筋トレ／トレッドミル型／バイク型 から選ぶ | 筋トレ |
| 鍛える筋肉 | ○（1つ以上。筋トレのみ） | 部位ごとにまとめた一覧から複数選択 | なし |
| 重量の刻み幅 | ○（筋トレのみ） | 数値（kg）。0.5〜10、小数第1位まで | 2.5 |
| 固定メモ | — | テキスト（例：シート位置、ピンの番号） | 空 |

- 種類で有酸素を選ぶと、鍛える筋肉と重量の刻み幅は出さず、記録する項目を案内する。
- 記録がある種目は、種類を変えられない（記録の項目が合わなくなるため）。
- 鍛える筋肉の一覧の下に「その他の筋肉」を置く。筋肉の名前を入れ、部位を選んで［追加］を押すと、その部位の一覧にチェックされた状態で加わる。
  - 名前が空、または部位が未選択なら追加しない（理由を表示する）。
  - すでにある筋肉と同じ名前なら、新しく作らずにその筋肉にチェックを入れる。
  - 削除した筋肉と同じ名前なら、新しく作らずにその筋肉を戻してチェックを入れる（部位を選んでいればその部位に移す）。
  - 追加した筋肉は、種目を保存したときに筋肉リストへ保存する。チェックを外した追加分や、保存せずに画面を離れた場合は保存しない。
- 同じ名前の種目がすでにあれば、保存できない。
- 記録がある種目は削除できない。代わりに［非表示にする］（非表示なら［再び表示する］）ボタンを置く。記録がない種目は削除できる（確認ダイアログを出す）。

## 3. 辛さの定義

| 値 | 表示 | 色 | 目安（筋トレ） | 目安（有酸素） |
|---|---|---|---|---|
| 1 | 余裕 | 緑 | まだかなり回数を重ねられる | 会話しながら楽に続けられる |
| 2 | やや楽 | 黄緑 | 少し余力がある | 少し息が上がるが、まだ余裕がある |
| 3 | 普通 | 黄 | ほどよくきつい | 息は上がるが、続けられる |
| 4 | きつい | オレンジ | あと1〜2回が限界 | 会話がつらい。あと少しで限界 |
| 5 | 限界 | 赤 | もう1回もできない | これ以上は続けられない |

- 色は、ライト表示・ダーク表示のどちらでも文字が読める濃さにする。
- 色が見分けにくい場合にも分かるように、**必ず言葉を併記する**。
- 「目安」は主観で選ぶための説明で、医学的な基準ではない。使いながら文言を調整してよい。

## 4. 筋肉リスト（初期値）

ジムの種目説明でよく使われる名前を、部位ごとにまとめた。S-7 の「その他の筋肉」から追加できる。

| 部位 | 筋肉 |
|---|---|
| 胸 | 大胸筋 |
| 背中 | 広背筋、僧帽筋、脊柱起立筋 |
| 肩 | 三角筋前部、三角筋中部、三角筋後部 |
| 腕 | 上腕二頭筋、上腕三頭筋、前腕 |
| 体幹 | 腹直筋、腹斜筋 |
| 脚・お尻 | 大殿筋、中殿筋、大腿四頭筋、ハムストリングス、内転筋、ふくらはぎ（下腿三頭筋） |

## 5. データ項目定義

### 5.1 種目（exercise）
| 項目 | 型 | 内容 |
|---|---|---|
| id | 文字列 | 一意のID（自動） |
| name | 文字列 | 種目名（他の種目と重複しない） |
| kind | 文字列 | `strength`（筋トレ）／`treadmill`（トレッドミル型）／`bike`（バイク型）。ない場合は筋トレとみなす（0.1 で作った種目との互換のため） |
| muscleIds | 文字列の配列 | 鍛える筋肉のID（筋トレは1つ以上、有酸素は空） |
| weightStep | 数値 | 重量の刻み幅（kg）。有酸素では使わない（値は入っているが無視する） |
| fixedNote | 文字列 | 固定メモ（空でもよい） |
| hidden | 真偽値 | 非表示なら true |
| createdAt | 日時 | 登録日時 |

最初から登録する有酸素の種目：「トレッドミル」（トレッドミル型）、「エアロバイク」「リカンベントバイク」（バイク型、固定メモ「背もたれのあるバイク」）。登録は1回だけ行い、同じ名前の種目がすでにあれば、その種目は登録しない。

### 5.2 筋肉（muscle）
| 項目 | 型 | 内容 |
|---|---|---|
| id | 文字列 | 一意のID |
| name | 文字列 | 筋肉名 |
| group | 文字列 | 部位（胸／背中／肩／腕／体幹／脚・お尻） |
| builtin | 真偽値 | 最初から用意したものなら true |
| hidden | 真偽値 | 設定画面で削除したら true（データは残す。S-7 の一覧や履歴の絞り込みには出さない） |
| order | 数値 | 表示順。初期値は筋肉リストの順、追加したものはその後ろ |

### 5.3 記録（record）
1件 ＝ 筋トレは1セット、有酸素は1回。

| 項目 | 型 | 内容 |
|---|---|---|
| id | 文字列 | 一意のID（自動） |
| exerciseId | 文字列 | 種目のID |
| performedAt | 日時 | 記録日時（端末の現地時刻、時差つき。例：`2026-10-12T19:42:05+09:00`） |
| weightKg | 数値 | 筋トレのみ。重量（kg）。ダンベルは片手1本の重さ |
| reps | 整数 | 筋トレのみ。回数 |
| durationMin など | 数値または null | 有酸素のみ。「5.4 有酸素の記録項目」。入れなかった項目は null |
| difficulty | 整数 | 辛さ（1〜5） |
| note | 文字列 | 備考（空でもよい） |

- **番号**（①②③…）は保存せず、「同じ日・同じ種目の記録を日時順に並べた順番」として表示時に計算する。
- 「同じ日」は、端末の現地時刻で日付が同じことを指す。

### 5.4 有酸素の記録項目

| 項目名 | 表示 | 単位 | 範囲 | 小数 | トレッドミル型 | バイク型 | 記録画面の入力 | グラフの1日の値 |
|---|---|---|---|---|---|---|---|---|
| durationMin | 時間 | 分 | 1〜300 | なし | ○（必須） | ○（必須） | −／＋（1分） | 合計 |
| speedKmh | 速度 | km/h | 0.1〜30 | 1位まで | ○ | — | −／＋（0.5km/h） | 最大 |
| inclinePct | 傾斜 | % | -5〜40 | 1位まで | ○ | — | −／＋（0.5%） | 最大 |
| level | レベル | — | 0〜30 | なし | — | ○ | −／＋（1） | 最大 |
| rpm | 回転数 | rpm | 0〜200 | なし | — | ○ | −／＋（5rpm） | 最大 |
| distanceKm | 距離 | km | 0〜100 | 2位まで | ○ | ○ | 数値（任意） | 合計 |
| kcal | カロリー | kcal | 0〜3000 | なし | ○ | ○ | 数値（任意） | 合計 |

- 必須は **時間と辛さだけ**。ほかは、マシンによって表示されない値があるので空欄でもよい。
- 速度・傾斜・レベル・回転数は1回の記録につき1つの値。途中で変えた場合は主に使った値を入れるか、区間ごとに分けて記録する。
- **範囲の決め方**：どの機種の値でも入るように、調べた業務用マシンの値より広くとった。調べた値と確認の程度は次のとおり。

| 項目 | 調べた値 | 確認の程度 | 出典（参照日） |
|---|---|---|---|
| 速度 | Matrix Fitness 0.8〜26 km/h、Precor 0.8〜25.5 km/h | 検索結果の要約のみ。ページ本体は取得できなかった | https://www.medicalexpo.com/ja/seizomoto-iryo/kiwado-601.html （2026-10-13） |
| 速度 | Gymleco Alpha Runner 1〜25 km/h | 検索結果の要約のみ | https://gymleco.com/product/alpha-runner-commercial-treadmill （2026-10-13） |
| 傾斜 | 0〜20% のもの、-5〜40% の高傾斜モデル | 検索結果の要約のみ。どのページの記述かは特定できていない | — |

## 6. 入力チェック

| 項目 | 条件 | 条件を満たさないとき |
|---|---|---|
| 重量 | 0〜100 の数値、小数第1位まで | 記録ボタンを押せない。理由を表示する |
| 回数 | 1〜100 の整数 | 同上 |

## 7. 書き出し・読み込みの形式

### 7.1 CSV（分析用）
- 文字コード：UTF-8（BOM付き。Mac の Excel で文字化けしにくくするため）、改行は CRLF。
- 1行 ＝ 1件の記録、日時の古い順。ファイル名：`gym_log_records_YYYYMMDD.csv`
- 列：

| 列名 | 例 | 備考 |
|---|---|---|
| date | 2026-10-12 | |
| time | 19:42 | 秒は出さない |
| exercise | チェストプレス | 種目が消えていれば「(削除された種目)」 |
| kind | 筋トレ | 筋トレ／トレッドミル型／バイク型 |
| muscles | 大胸筋;三角筋前部;上腕三頭筋 | `;` 区切り。有酸素は空 |
| groups | 胸;肩;腕 | `;` 区切り。有酸素は「有酸素」 |
| set_no | 1 | 同じ日・同じ種目の中の番号 |
| weight_kg | 40 | 筋トレのみ |
| reps | 10 | 筋トレのみ |
| duration_min | 30 | 有酸素のみ（以下 kcal まで同じ）。入れていなければ空 |
| speed_kmh | 8 | |
| incline_pct | 2.5 | |
| level | 8 | |
| rpm | 70 | |
| distance_km | 3.2 | |
| kcal | 250 | |
| difficulty | 3 | |
| difficulty_label | 普通 | |
| note | 最後の1回は補助あり | 記録の備考（種目の固定メモではない） |

- CSV には、種目の固定メモ・非表示・記録のID・秒を含めない。そのため **CSV からは復元できない**（復元は 7.2 のバックアップから）。

### 7.2 バックアップ（復元用）
- 種目・筋肉・記録をすべて含む JSON ファイル。ファイル名：`gym_log_backup_YYYYMMDD.json`
- 形式：

```json
{
  "app": "gym_log",
  "schemaVersion": 1,
  "exportedAt": "2026-10-13T21:05:00+09:00",
  "exercises": [ { "id": "…", "name": "チェストプレス", "kind": "strength", "…": "5.1 の項目" } ],
  "muscles":   [ { "id": "chest-pectoralis", "name": "大胸筋", "…": "5.2 の項目" } ],
  "records":   [ { "id": "…", "exerciseId": "…", "…": "5.3 の項目" } ]
}
```

- `schemaVersion` を上げる条件はアーキテクチャ設計書「5.3 データ形式の変更」のとおり。項目を足しただけで、ない場合に既定値で扱えるもの（例：`kind`、筋肉の `hidden`）は上げない。
- **読み込むときの確認**：次のどれかに当てはまれば、理由を表示して読み込まない。
  - JSON として読めない／`app` が `gym_log` でない／`schemaVersion` がこのアプリより新しい
  - `exercises`・`muscles`・`records` のどれかがない、または ID のない項目がある
  - 存在しない種目を指す記録がある／同じ名前の種目が2つ以上ある
- **復元するとき**
  - 確認ダイアログで件数を示し、今のデータが消えること、残したいなら先に書き出すことを伝える。
  - 種目・筋肉・記録をすべて置き換える。
  - 設定値（アーキテクチャ設計書 5.1）は次のように扱う。
    - 最後に選んだ種目：消す（復元したデータにない種目かもしれないため）。
    - 最終バックアップ日時：復元した時刻にする（今のデータは読み込んだファイルと同じ内容のため）。
    - 有酸素マシンの登録済みの印：消して、もう一度登録を行う。有酸素を追加する前のバックアップから復元しても、有酸素マシンが入るようにするため。同じ名前の種目があれば登録しない。
    - ホーム画面への追加の案内を閉じたこと：そのまま残す。

## 8. データ保全のための仕組み

- 起動したとき、ブラウザにデータの永続化を要求する（`navigator.storage.persist()`）。結果は設定画面に表示する。
- Safari のタブで開いているときは、ホーム画面への追加を案内する（「1」の画面上部の案内）。
- 最後にバックアップを書き出してから **7日** 経ったら、画面上部に案内を出す。まだ一度も書き出していない場合は、最初の記録から7日経ったら出す。
- 書き出したかどうかは、共有シートで何かを選んだ時点で「書き出した」とみなす（「"ファイル"に保存」以外を選んでも区別できない）。そのため S-6 で保存先の選び方を案内する。
