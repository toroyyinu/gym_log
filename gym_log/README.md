<h1 align="center">頑張れジム通い</h1>

<p align="center">
  ジムでの筋トレと有酸素運動を、iPhone で手早く記録するための個人用 Web アプリ。<br>
  記録は端末の中だけに保存し、外部には送りません。
</p>

---

## 特徴

- **片手で数タップ**：前回の値が最初から入っているので、同じ重さなら「辛さ」を押して記録するだけ。
- **前回がすぐ分かる**：種目を選ぶと、前回やった日の記録が出る。押すとその値を入力欄に入れられる。
- **筋トレと有酸素の両方に対応**
  - 筋トレ：重量・回数・辛さ（5段階、言葉と色）・備考
  - 有酸素：トレッドミル型（時間・速度・傾斜・距離・カロリー）、バイク型（時間・レベル・回転数・距離・カロリー）
- **鍛える筋肉で整理**：種目ごとに筋肉を選んでおくと、部位や筋肉で履歴を絞り込める。
- **推移グラフ**：筋トレは最大重量、有酸素は時間・速度などを切り替えて見られる。
- **オフラインで動く**：ホーム画面に追加すれば、電波の弱いジムでも使える（PWA）。
- **プライバシー**：サーバーなし、アクセス解析なし、外部ライブラリなし。記録は IndexedDB にだけ保存。
- **書き出し**：分析用の CSV と、復元用のバックアップ（JSON）。7日ごとにバックアップを促す。

## 使い方（iPhone）

1. Safari で公開 URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く。
2. 共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから起動する。
   ホーム画面に追加すると、Safari のタブで開くよりデータが消えにくくなります。
3. 「記録」タブで種目を選び、記録する。筋トレの種目は「＋ 新しい種目を登録」から自分のジムのマシンを登録する（有酸素マシン3種は最初から入っています）。
4. ときどき「設定」→「バックアップを書き出す」で、共有シートの「"ファイル"に保存」を選んで保存しておく。

> **データについて**
> 記録はこの端末のこのアプリの中にだけあります。iPhone を替えるときや、万一データが消えたときは、書き出したバックアップから「設定」→「バックアップから復元」で戻せます。

## 構成

| | |
|---|---|
| 言語 | HTML・CSS・JavaScript（ES Modules）。フレームワーク・ビルドなし |
| 保存先 | IndexedDB（端末内） |
| 公開 | GitHub Pages（静的ファイルのみ） |
| オフライン | Service Worker（`sw.js`）でアプリ本体をキャッシュ |

```
index.html            外枠（タブバー、記録編集シート、共通部品）
views/*.html          各画面の表示
js/views/*.js         各画面の処理（views/ と同じ名前で対応）
js/domain.js          記録のルール（前回記録、入力チェック、有酸素の項目など）
js/db.js              IndexedDB の読み書き
css/style.css         見た目（ライト・ダーク）
sw.js                 Service Worker
tests/                単体テスト・通しテスト
tools/serve.py        Mac で試すための簡易サーバー
docs/                 設計書
```

表示（HTML）と処理（JS）を別ファイルに分け、JS は HTML の文字列を組み立てずに `<template>` と `data-*` 属性で値を差し込む作りにしています。詳しくは設計書を参照してください。

## 開発

### Mac で動かす

```sh
python3 tools/serve.py
```

Safari で http://localhost:8000 を開く。

- `python3 -m http.server` でも動くが、Safari が古いファイルを使い続けて画面と処理が食い違うことがあるので、`tools/serve.py`（毎回最新を確かめさせる）を使う。
- localhost では Service Worker を登録しない。試すときは http://localhost:8000/?sw を開く。
- localhost で保存したデータは、公開 URL のデータとは別物。

### テスト

サーバーを起動したまま、次を開く。

| ページ | 内容 |
|---|---|
| http://localhost:8000/tests/ | 単体テスト（記録のルール、入力チェック、CSV、バックアップ、グラフの値） |
| http://localhost:8000/tests/e2e.html | 画面を実際に操作する通しテスト |

通しテストは、**開いたブラウザのアプリにテスト用の種目・記録を追加する**ので、普段使うブラウザでは開かないこと。公開先のデータを守るため、localhost 以外では動かないようにしてある。

### 公開（GitHub Pages）

1. このフォルダの中身をリポジトリの直下に置いて push する。
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にする。
3. 表示された URL を iPhone の Safari で開き、ホーム画面に追加する。

### 更新するとき

1. ファイルを直し、単体テストと通しテストがすべて成功することを確かめる。
2. `sw.js` の `VERSION` を上げる（ファイルを増やした・消したときは `ASSETS` も直す）。上げないと、iPhone は古いファイルを使い続ける。
3. `js/domain.js` の `APP_VERSION` を上げる。
4. push する。iPhone でアプリを開くと「新しい版があります」と出るので［更新する］を押す。

どの番号をいつ上げるかの詳細は、[アーキテクチャ設計書「9.1 公開・更新の手順」](docs/03_アーキテクチャ設計書.md) にあります。
